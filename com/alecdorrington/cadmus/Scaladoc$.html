inline def of[A]: Option[Scaladoc]

Reads the comment of a type: a class, trait, object, type alias or opaque type by its own, and a singleton type, as a case object's or an enum's case of no fields, by that of its term.

Reads the comment of a type: a class, trait, object, type alias or opaque type by its own, and a singleton type, as a case object's or an enum's case of no fields, by that of its term.

Scala keeps the comment of a type it compiles from source in the same run as the call, as it always does where the call is in the type's own file (in a derives clause, or a given in its companion). That of a type compiled before, as one from a library or from a file not recompiled since, it reads from the type's TASTy only with the compiler option -Xread-docs. A Java class has none.

Reads the comment of a field or method of a type, as of reads the type's. Scala keeps no comment written on a class's parameter, so a field of one has none; its class's @param tag describes it instead.

def parse(comment: String): Scaladoc

Reads a comment into its parts. A tag starts a line outside any code example, and runs to the next. A macro of one's own may read a symbol's comment this way, as symbol.docstring.map(Scaladoc.parse).

Reads a comment into its parts. A tag starts a line outside any code example, and runs to the next. A macro of one's own may read a symbol's comment this way, as symbol.docstring.map(Scaladoc.parse).
